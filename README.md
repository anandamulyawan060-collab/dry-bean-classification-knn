# Dry Bean Classification using KNN

## Deskripsi Project
Project ini merupakan praktikum Machine Learning untuk melakukan klasifikasi jenis kacang menggunakan algoritma **K-Nearest Neighbors (KNN)** dengan bahasa pemrograman Python. Dataset yang digunakan adalah Dry Bean Dataset yang berisi karakteristik fisik kacang untuk membantu proses klasifikasi.

## Tujuan
- Memahami proses membaca dan mengolah dataset menggunakan Python.
- Melakukan eksplorasi dan persiapan data sebelum klasifikasi.
- Menerapkan algoritma K-Nearest Neighbors (KNN).
- Mengevaluasi hasil klasifikasi menggunakan metrik evaluasi.

## Dataset
Dataset Dry Bean berisi 13.611 data dengan 17 kolom, yang mencakup fitur karakteristik kacang dan kelas jenis kacang.

## Tools dan Library
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Metode
Algoritma KNN digunakan untuk mengklasifikasikan jenis kacang berdasarkan kemiripan karakteristik datanya. Tahapan praktikum meliputi membaca dataset, eksplorasi data, pembagian data training dan testing, standardisasi fitur, penerapan KNN, serta evaluasi model.

## Evaluasi
Evaluasi model dilakukan menggunakan accuracy, precision, recall, F1-score, dan confusion matrix untuk melihat performa klasifikasi.

## File Project
- `dataset klarifikasi kacang.ipynb` — notebook berisi kode dan tahapan praktikum.

## Kesimpulan
Project ini membantu memahami penerapan algoritma KNN untuk klasifikasi data serta tahapan pengolahan dan evaluasi model Machine Learning menggunakan Python.
